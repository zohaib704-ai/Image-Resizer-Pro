How to resize a photo

Set exact pixel dimensions without distorting the image, using the aspect-ratio lock.

Jan 11, 2026 4 min read By the editors

What this tool does

The Resize tool lets you enter a target width and height in pixels. With Lock aspect ratio enabled (the default), changing one dimension automatically recalculates the other — so the image never squishes or stretches. When you click Apply Resize, the canvas is redrawn at the new dimensions using high-quality downscaling.

When to use it

  • Meeting an upload form's pixel cap (e.g. "max 1200 × 1200 px").
  • Making thumbnails for a website or email.
  • Matching a display size so the browser doesn't downscale (which wastes bandwidth).
  • Preparing images for a specific print size.

Step-by-step

  1. Upload your image and open the Resize tool. The current dimensions appear in the fields.
  2. Keep Locked selected under the ratio dropdown — this is what prevents distortion.
  3. Change Width to your target. The height updates automatically.
  4. Or change Height — the width updates to match.
  5. Click Apply Resize.

Tips for best results

  • Downscale, don't upscale. Shrinking an image looks clean. Enlarging it stretches pixels and produces blur. Never upscale unless you have no choice.
  • Downscale in steps for very large reductions. Halving 4000 → 2000 → 1000 looks better than jumping straight from 4000 → 1000. (This app handles it automatically, but good to know.)
  • Match the display size. If your site shows the image at 600px wide, don't serve a 3000px file. Browsers shrink it visually, but the full file still downloads.
  • Resize before compressing. Fewer pixels = a smaller compressed file for the same visual quality.

Common mistakes

  • Upscaling a small photo. A 500px photo blown up to 2000px is blurry no matter what. Start with a bigger source or accept the small size.
  • Unlocking the ratio by accident. You get a stretched image. If you need a different shape, crop instead — don't distort.
  • Entering 0 or leaving a field empty. The tool rejects invalid sizes; if you see no change, check the values.
  • Resizing after cropping to a ratio. You can resize after cropping — that's fine. What's wrong is resizing to fix a crop you got wrong. Crop first, resize second.
