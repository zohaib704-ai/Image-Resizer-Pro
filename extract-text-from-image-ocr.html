OCR

Extract text from any image — for free, in the browser

You don't need to upload a screenshot to a server to copy its text. Modern browsers can do it locally.

Jan 4, 2026 7 min read By the editors

What OCR actually does

Optical Character Recognition (OCR) takes an image containing text and converts it back into selectable characters. The classic approach finds "blobs" that look like letters, segments them, and matches them against trained character models. Modern engines — including Tesseract, the open-source engine that Tesseract.js wraps — use neural networks and are dramatically more accurate on noisy scans and photos.

Historically OCR required server-side processing because the models were large and the compute was heavy. That's no longer true. Tesseract.js ships as WebAssembly, downloads a language model once (a few MB), then runs entirely inside your browser tab.

What you can realistically extract

  • Scanned documents — printed text, book pages, receipts, forms.
  • Screenshots — code snippets, error messages, chat logs.
  • Photos of signs, menus, or whiteboards — if the text is clear and reasonably straight.
  • Handwriting — poorly. Tesseract was trained on printed text; cursive handwriting is unreliable.

Getting good results: five rules

  1. Use the highest resolution you have. 300 DPI is the sweet spot for scanned text. Downscaling hurts accuracy.
  2. Deskew and straighten. A 5° tilt cuts accuracy noticeably. If you can crop and rotate first, do so.
  3. Improve contrast. Grey text on grey background confuses the engine. Push contrast up before running OCR.
  4. Pick the right language. The engine needs the language model for the text's language. English text with the Urdu model loaded will produce nonsense.
  5. Crop out everything that isn't text. Logos, photos, and borders introduce noise. A tight crop gives cleaner output.

How to do it in ImageResizer Pro

  1. Upload your image on the homepage.
  2. If needed, use Crop to trim to the text area, then Enhance to raise contrast.
  3. Open Read Text (OCR) and select the correct language.
  4. Click Extract Text. First run downloads the language model (~10–15 seconds); subsequent runs are fast.
  5. Copy the result with the Copy Text button.

Nothing is uploaded. The language model is downloaded from Tesseract's CDN once, then cached by your browser.

What the output looks like

Tesseract returns plain text with line breaks inferred from the layout. It doesn't preserve font sizes, bold/italic, or columns — just text in reading order. If your source is a two-column PDF screenshot, expect the engine to occasionally interleave the columns. Cropping each column separately fixes this.

Accuracy in numbers

For clean, high-resolution, straight, printed English text, Tesseract 5 typically achieves 98–99% character accuracy. For phone photos of documents, expect 90–95%. For handwriting, accuracy drops to 30–60% — it's simply not what the engine was designed for.

When NOT to use browser OCR

If you're processing thousands of pages, or need to preserve complex layouts (tables, forms with precise field positions), a server-side OCR pipeline with layout analysis (like Google Document AI or AWS Textract) will beat any browser tool. For occasional single-image extraction, though, running locally is faster, free, and private.
